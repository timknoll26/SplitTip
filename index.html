DAS PROBLEM

Gleich aufteilen ist nicht gleich fair.

Wer am ruhigen Dienstagmittag zwei Stunden aushilft, bekommt beim klassischen Kopfteiler genauso viel wie jemand, der die komplette Freitagabend-Rush durchgestanden hat. Das ist schnell gerechnet, fühlt sich aber für niemanden richtig an, der die Stoßzeit getragen hat.

SplitTip löst das über Zeitfenster: Wer während einer markierten Stoßzeit im Dienst war, bekommt für genau diese überlappenden Minuten einen höheren Anteil — der Rest der Schicht zählt normal.

ABLAUF

Drei Schritte bis zur Auszahlung

01

Schicht erfassen

Balken auf der Zeitachse ziehen, statt Formularfelder auszufüllen — auf die Minute genau, nicht auf halbe Stunden gerundet.

02

Stoßzeit markieren

Ein Zeitfenster wie „Stoßzeit Abend", 18:00–21:00 Uhr, mit eigenem Multiplikator — z. B. 1,3×.

03

Automatisch verteilen

Überlappende Minuten zählen mit Multiplikator, der Rest mit 1,0×. Rundung verteilt danach jeden Cent.

// für jede Person, pro Stoßzeitfenster
overlap = intersect(shift, window)
weighted = overlap * window.multiplier
    + (shift.duration - overlap) * 1.0

FUNKTIONEN

Gebaut für die Theke, nicht fürs Büro

Schicht-Matrix

Balken statt Formularfelder — ziehen, verschieben, an den Kanten kürzen. Auch am Tablet per Touch.

Ohne Anmeldung

Läuft komplett im Browser — kein Account, kein Server. Speichert automatisch in diesem Browser.

Cent-genau

Largest-Remainder-Rundung garantiert: Die Summe stimmt immer exakt.

WhatsApp-Export

Ergebnis als fertiger Text zum Teilen — kein PDF nötig.
